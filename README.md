# Flappy Dox 🐶

A Flappy Bird–style game starring a chocolate dapple dachshund who flies by flapping her long ears.
Tap (or press Space) to flap past the fire hydrants and lamp poles in the park.

Play it on your phone, then use **Share → Add to Home Screen** to install it like an app. It works offline once it's been opened.
